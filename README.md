# ובא לציון גואל

מדריך הנחיות לצוותי חירום רפואיים.

## מבנה הפרויקט

```
mda-guide/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── images/
    ├── ambulance-left.png
    └── ambulance-right.png
```

## הרצה מקומית

פתחו את `index.html` בדפדפן, או הריצו שרת מקומי:

```bash
python3 -m http.server 8000
```

ואז גשו ל-http://localhost:8000
